# Mod page images

Images shown on the CurseForge and Modrinth pages of THEFricadelle's Minecraft mods: animated
banners, section titles, badges and icons. One folder per mod. The pages load them through jsDelivr:

```
https://cdn.jsdelivr.net/gh/THEFricadelle/mc-mods-images@main/<mod>/<file>
```

The files are generated by the page tools kept in each mod's own repository. Do not edit them
here: rebuild them there and copy the result over.

| Folder | Mod |
|---|---|
| `better-creative/` | Better Creative |

# Images des pages de mods

Images affichées sur les pages CurseForge et Modrinth des mods Minecraft de THEFricadelle :
bannières animées, titres de section, badges et icônes. Un dossier par mod. Les pages les chargent
via jsDelivr :
